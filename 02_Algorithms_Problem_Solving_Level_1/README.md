\# 📘 02 - Algorithms \& Problem-Solving - Level 1



📣 \*\*Learn how to think before you write code, otherwise you will be a weak developer!\*\*



\---



\## 🗝️ About This Course



\*\*Algorithms and Problem Solving – Level 1\*\* is the \*\*second course\*\* in the programming learning journey, after:



\*\*01 - Programming Foundations - Level 1\*\*



In the first course, the focus was on understanding \*\*how computers work, how data is represented, and how programs are built at a conceptual level\*\*.



This course focuses on one of the most important skills in programming:



👉 \*\*How to think and solve problems correctly.\*\*



The course introduces \*\*algorithms and problem solving without using any programming language\*\*.



The goal is to learn how to \*\*analyze problems, break them down into smaller steps, and design clear solutions using flowcharts\*\* before writing code.



\---



\## 🎯 Course Objectives



The main objectives of this course are to:



\* 🧠 Develop algorithmic and logical thinking.

\* 🔍 Learn how to analyze problems before coding.

\* 🧩 Break complex problems into simple, manageable steps.

\* 📊 Design solutions using flowcharts.

\* 🔄 Identify inputs, processes, decisions, and outputs.

\* 💡 Develop independent problem-solving skills.

\* 🚫 Learn problem solving without depending on programming syntax.

\* 💻 Build a strong foundation for programming with C++.



\---



\## 📚 Course Content



This course is built around \*\*practice-driven problem solving\*\* rather than programming syntax.



The course covers:



\* 🧠 Algorithms and algorithmic thinking.

\* 🔍 Problem analysis.

\* 🧩 Step-by-step problem decomposition.

\* 📊 Flowcharts and visual thinking.

\* 🔄 Inputs, processes, decisions, and outputs.

\* 💡 Logical analysis and structured reasoning.

\* 📝 \*\*50 carefully selected problems\*\* designed to develop problem-solving skills.



No programming language is used during this course.



The problems solved here will later be \*\*re-solved using C++\*\* in the next course.
