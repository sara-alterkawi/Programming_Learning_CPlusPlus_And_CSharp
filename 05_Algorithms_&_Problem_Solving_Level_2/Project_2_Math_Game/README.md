# 🧮 Math Game

🎯 **About the Project**

A **fun and interactive command-line math game** where the player answers randomly generated math questions.

**Skills practiced:**

* ➕ Addition
* ➖ Subtraction
* ✖ Multiplication
* ➗ Division
* 🟢 Conditional statements
* 🔄 Loops
* 🎲 Random number generation
* ⚙️ Functions

---

## 🛠 Built With

* 💻 **Language:** C++
* 📚 **Libraries:** `<iostream>`, `<cstdlib>`, `<ctime>`

---

## 🚀 Features

* 🎯 Real-time arithmetic challenges.
* ⏱ Measures response time and accuracy.
* 🧩 Randomly generated questions for replayability.
* 📌 Modular design with functions for clarity and reusability.

---

## 🔧 How to Run

1. Clone the repository:

```bash
git clone https://github.com/sara-alterkawi/math-game.git
```

2. Open the project in **Visual Studio** or **Dev-C++**.
3. Compile and run the code.
4. Start answering math questions and track your score!
