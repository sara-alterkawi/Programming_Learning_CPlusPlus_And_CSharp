# 🧩 Algorithms & Problem Solving – Level 2

🎯 **About the Project**

The focus of this level was on **enhancing problem-solving skills** while applying the **Divide & Conquer** approach and **structured programming principles**.

**Skills practiced:**

* 🧠 Algorithmic thinking
* 🟢 Structured programming
* 🔹 Function decomposition and design
* 🛠 Debugging and optimization
* 🎯 Implementing custom functions instead of built-in cmath ones:

  * `abs()`, `round()`, `floor()`, `ceil()`, `sqrt()`
* 🔄 Applying Divide & Conquer techniques
* 📌 Modular and reusable code design

---

## 🛠 Built With

* 💻 **Language:** C++
* 🧩 **Paradigm:** Structured Programming
* 🛠 **Tools:** VS Code / Dev-C++, Git, GitHub

---

## 🚀 Features

* 🧩 Step-by-step problem solving using Divide & Conquer
* 🔹 Decomposed each problem into small, focused functions
* 📌 Avoided reliance on built-in math functions
* 🛠 Two hands-on projects applying all learned concepts
* 💡 Focus on readability, maintainability, and modularity
