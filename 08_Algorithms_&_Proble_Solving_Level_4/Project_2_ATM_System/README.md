💳 **ATM – C++ Console Application**
**Project 5**
A C++ console-based ATM System built with a focus on simplicity, efficiency, and clean coding practices. It provides a hands-on learning experience for understanding real-world banking operations and applying core C++ concepts effectively.
---

## 🏦 About the Project

This application simulates key ATM functionalities — such as balance inquiry, deposits, and withdrawals — while emphasizing usability, structured program design, and robust functionality.
---

## 📌 Core Features (ATM)

* **Secure Login:** – Ensures user authentication through a valid account number and PIN verification.
* **Quick Withdraw:** – Offers predefined withdrawal options for fast and convenient cash access.
* **Custom Withdraw:** – Allows personalized withdrawal amounts with validation to ensure multiples of 5.
* **Deposit:** – Enables users to add funds with immediate balance updates.
* **Balance Inquiry:** – Instantly displays the user’s current account balance and details.
* **File Handling:** – Implements persistent data storage using text files to maintain transaction records and data integrity.
---

## 🛠 Tech Stack

* **Language:** C++
* **Paradigm:** Structured Programming
* **Data Storage:** Text files
* **Platform:** Console (Terminal)
---

## 🎯 Technical Highlights & Learning Outcomes:

* Modular Design: Clean, maintainable structure with reusable functions.
* Efficient Data Handling: Uses structs and vectors to manage client information.
* Robust Validation: Prevents invalid operations and ensures user safety.
* File I/O: Reliable reading/writing of client data for data consistency.
* Core Concepts Practiced: File handling, menu-driven design, data validation, and scalable project development.
