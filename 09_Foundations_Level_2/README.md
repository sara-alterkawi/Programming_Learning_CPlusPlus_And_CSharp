# 📘 09 - Foundations - Level 2

📣 **Build deeper foundations 🌐⚙️ before moving into advanced programming concepts**

---

## 🗝️ About This Course

**Foundations – Level 2** is an intermediate foundations course in the programming learning journey.

This course builds on the knowledge gained from the previous foundations and programming courses and introduces important concepts related to **computer networks, the Internet, software architecture, data formats, business intelligence, security, and software engineering**.

The goal is to develop a broader understanding of the technologies and concepts that software developers work with beyond programming languages and code.

---

## 🎯 Course Objectives

The main objectives of this course are to:

* 🌐 Understand computer networks and how the Internet works.
* 🔄 Understand how data is transferred between systems.
* 🌍 Learn about IP addresses, TCP, DNS, HTTP/HTTPS, and other Internet protocols.
* 🖥️ Understand servers, routers, gateways, modems, and other networking concepts.
* 🔐 Build a basic understanding of networking and software security.
* 🏗️ Understand software architectures such as **N-Tier and 3-Tier Architecture**.
* 📦 Understand common data formats such as **XML and JSON**.
* 🔌 Understand what APIs are and how applications communicate.
* 📊 Learn the basics of **Business Intelligence and OLAP Cubes**.
* 👨‍💻 Develop a broader understanding of the role of a software engineer.
