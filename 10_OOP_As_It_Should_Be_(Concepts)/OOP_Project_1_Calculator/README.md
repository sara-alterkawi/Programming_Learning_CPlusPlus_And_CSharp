🧮**Calculator – C++ OOP Console Application**
**Project 1**
A simple C++ console-based Calculator built using Object-Oriented Programming (OOP) principles.
This project focuses on clean class design, encapsulation, and method-based arithmetic operations, making it ideal for practicing core OOP concepts in C++.
---

## 🔢 About the Project

This application simulates a basic calculator that performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division.
It also includes utility features like clearing results, undoing the last operation, and printing operation history — all managed through a dedicated Calculator class.

The project is designed to demonstrate how real-world objects (like a calculator) can be modeled using classes, private data members, and public methods.
---

## 📌 Core Features (ATM)

* **Addition:** – Adds a number to the current result.

* **Subtraction:** – Subtracts a number from the current result.

* **Multiplication:** - Multiplies the current result by a given number.

* **Division:** - Divides the current result with protection against division by zero.

* **Clear:** - Resets the calculator to its initial state.

* **Cancel Last Operation:** - Reverts the result to the previous value before the last operation.

* **Result Printing:** - Displays the current result along with the last operation performed.

## 🎯 Technical Highlights & Learning Outcomes:

* **Encapsulation:**
All calculator data (result, last number, last operation) is kept private and accessed only through class methods.

* **Class-Based Design:**
A dedicated clsCalculator class models calculator behavior realistically.

* **State Management:**
Tracks previous results to support undo (cancel last operation) functionality.

* **Input Safety:**
Handles division by zero gracefully to prevent runtime errors.

* **Clean & Readable Code:**
Well-structured methods with clear responsibilities, ideal for beginners learning OOP.

* **Core Concepts Practiced:**
Classes, constructors, private/public access modifiers, method design, and console output.
