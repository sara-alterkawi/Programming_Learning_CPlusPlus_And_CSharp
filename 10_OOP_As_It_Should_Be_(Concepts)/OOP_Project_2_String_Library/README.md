🧮**String Library – C++ OOP Console Application**
**Project 2**
A C++ console program demonstrating how a string library can be implemented using object-oriented programming.

The project showcases creating a clsString class with multiple string manipulation methods, allowing controlled access, transformation, and analysis of string data.
---

## 🔢 About the Project

This application defines a clsString class that maintains a private string value and exposes methods to:
* Count words and letters
* Count vowels, capital letters, and small letters
* Convert text to uppercase/lowercase or invert cases
* Trim, split, join, replace, and reverse words
* Remove punctuations
* Invert the case of a specific letter
* Check if a character is a vowel

The design keeps the string private and exposes controlled setters/getters and static or instance methods to perform operations, demonstrating encapsulation and object behavior.---

## 📌 Core Features (String Library)
**✔Word & Letter Counting:**
– Count words, capital letters, small letters, vowels, or a specific letter in the string.

**✔ Case Manipulation:**
– Convert first letters, all letters, or invert case globally or for specific letters.

**✔ String Splitting & Joining:**
– Split string into a vector of words or join arrays/vectors with a delimiter.

**✔ String Cleaning:**
– Trim spaces from left, right, or both ends; remove punctuations.

**✔ Word Replacement & Reversal:**
– Replace a specific word or reverse the order of words.

**✔ Vowel Checking:**
– Determine if a character is a vowel.

**✔ Encapsulation & Safety:**
– _Value is private; all operations are performed through class methods or properties.

## 🎯 Technical Concepts Demonstrated:

* **Class Design:**
Models a string as an object with data (_Value) and multiple behaviors (methods).

* **Constructors:**
Supports both default and parameterized constructors to initialize string objects.
* **Encapsulation:**
Private _Value with controlled access via a property Value.

* **Method Organization:**
Static vs. instance methods demonstrate utility functions vs. object-specific operations.

* **String Manipulation Abstraction:**
Operations like trimming, splitting, joining, and case inversion show how real-world string manipulations can be encapsulated in a class.

* **Static Methods & Overloading:**
Illustrates overloading methods to handle both instance-level operations and operations on arbitrary strings.
