# 🧱 Object-Oriented Programming (OOP) – C++

🎯 **About the Project**

This repository represents a key transition in my programming journey: moving from **structured programming** to **object-oriented thinking**.
At this stage, the focus shifted from writing correct code to **designing correct systems** — systems that are maintainable, extensible, and aligned with real-world modeling.

The work here reflects a solid practical understanding of **core OOP concepts in C++** and how they interact together in real programs, not in isolation.

**Skills practiced:**

* 🧠 Object-oriented thinking and responsibility-driven design
* 🧩 Encapsulation, abstraction, inheritance, and polymorphism
* 🔐 Data protection using access specifiers and controlled interfaces
* 🏗 Designing robust class hierarchies and relationships
* 🔄 Managing object lifetime (construction, copying, destruction)
* 🛠 Using static members, methods, and shared state correctly
* 🔍 Understanding compile-time vs runtime behavior
* 📌 Writing clean, maintainable, and scalable C++ code

## 🚀 Features

* 🧱 Practical implementation of **all core OOP principles** in C++
* 🔐 Proper use of access specifiers to enforce encapsulation
* 🏗 Designed and tested multiple class hierarchies
* 🔄 Implemented constructors, copy constructors, and destructors
* 🧠 Applied polymorphism using virtual functions and overriding
* ⚙️ Used static members and methods for shared behavior and state
* 🔁 Worked with inheritance visibility, casting, and binding concepts
* 🤝 Applied friend functions and classes where design justified it
* 🧩 Organized complex designs using nested classes and structures
