🧰 **Utility Library – C++ OOP Console Component**  
**Project 5**

A reusable C++ utility library that provides common helper functionalities frequently required in real-world applications, implemented using clean object-oriented design.

This project focuses on building a centralized utility component that simplifies randomization, array operations, swapping, text processing, and basic encryption tasks in a structured and reusable manner.

---

## 📌 About the Project

The **Utility Library** is designed as a foundational component that can be reused across multiple applications.

It encapsulates frequently needed operations such as:
- Random data generation
- Array manipulation
- Generic swapping
- Text utilities
- Simple encryption and decryption

All functionality is implemented inside a single utility class (`clsUtil`) using static methods, making it easy to use without object instantiation.

---

## 🧩 Core Features (Utility Library)

- **✔ Random Number Generation**
  - Generate random integers within a specified range.

- **✔ Random Character Generation**
  - Generate random characters (capital letters, small letters, digits, or mixed).

- **✔ Random Word Generation**
  - Generate random words of configurable length.

- **✔ Random Key Generation**
  - Generate formatted random keys.
  - Generate multiple keys at once.

- **✔ Generic Swap Functionality**
  - Swap values of different data types:
    - Integers
    - Floating-point numbers
    - Strings
    - Custom objects (e.g., `clsDate`)

- **✔ Array Shuffling**
  - Shuffle arrays of integers and strings randomly.

- **✔ Array Filling with Random Data**
  - Fill arrays with:
    - Random numbers
    - Random words
    - Random keys

- **✔ Text Encryption & Decryption**
  - Encrypt text using a simple key-based shifting technique.
  - Decrypt encrypted text back to its original form.

- **✔ Formatting Utilities**
  - Generate tab spacing for formatted console output.

## 🎯 Technical Concepts Demonstrated

- **Static Utility Class Design**
  - All functionality provided through static methods without object creation.

- **Encapsulation**
  - Utility logic is isolated inside a single, well-defined class.

- **Generic Programming Concepts**
  - Swap functionality applied to multiple data types.

- **Array Manipulation**
  - Shuffling and filling arrays safely and efficiently.

- **Randomization Techniques**
  - Proper seeding and controlled random generation.

- **Reusability**
  - Designed to be reused across different projects and systems.

---

## ⚠️ Design Notes

- This library focuses on **utility functionality**, not business logic.
- Encryption is intentionally simple and meant for learning purposes, not production security.
- Validation and error handling are kept minimal to maintain clarity and focus.
