# 🧱 Data Structures – Level 1 | C++

[svg](https://github.com/sara-alterkawi)

🎯 **About the Project**

This repository represents the next stage in my programming journey: moving from **solving problems and designing programs** to **organizing data efficiently**.

At this stage, the focus is on understanding the fundamental data structures used to store, access, modify, and manage data in C++. The goal is not simply to learn how structures work, but to understand **why they exist, when to use them, and how their operations affect performance**.

The work in this repository focuses on building a strong foundation in **core data structures, Big O analysis, and practical implementation** rather than relying only on the C++ STL.

**Skills practiced:**

* 🧠 Understanding the role and purpose of data structures
* 📊 Analyzing **Time & Space Complexity** using Big O notation
* 🧩 Classifying data structures and choosing the appropriate structure
* 🧱 Working with arrays and matrices
* 📦 Understanding vectors and fundamental STL concepts
* 🥞 Implementing and using stacks
* 🚶 Implementing and using queues
* 🔗 Implementing **Singly Linked Lists**
* 🔗 Implementing **Doubly Linked Lists**
* 🔄 Implementing **Circular Linked Lists**
* 🧠 Understanding **Abstract Data Types (ADT)**
* 🗺️ Introduction to maps and their use cases
* 💾 Understanding binary data structures through practical examples
* ⚙️ Comparing data structures based on their operations and performance

## 🧠 Learning Approach

[svg](https://github.com/sara-alterkawi)

The focus of this repository is **understanding before optimization**.

Instead of using ready-made containers immediately, many structures are implemented manually to understand what happens internally.

For each structure, the focus is on:

* 🔍 How the structure stores data
* ➕ How elements are inserted
* ❌ How elements are deleted
* 🔎 How elements are searched
* 🔄 How elements are traversed
* 📊 How operations affect time complexity
* 🎯 When the structure is appropriate to use

The **C++ STL** is used as a supporting tool while maintaining an understanding of the underlying concepts.

## 📈 Complexity Analysis

[svg](https://github.com/sara-alterkawi)

A major part of this course is learning how to reason about performance using **Big O notation**.

The repository includes practical analysis of operations such as:

* Access
* Search
* Insertion
* Deletion
* Traversal

The goal is to understand that choosing a data structure is not only about making code work, but also about choosing an efficient way to organize and access data.
