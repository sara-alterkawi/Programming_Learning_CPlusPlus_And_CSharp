\# 🍕 Build Your Pizza



📣 \*\*Build your own pizza step-by-step and watch the total price update in real time!\*\*



\---



\## 🗝️ About This Project



\*\*Build Your Pizza\*\* is a desktop pizza ordering application developed using \*\*C# and Windows Forms\*\*.



The application allows users to customize their own pizza through a simple and visual ordering process.



Users can choose the \*\*pizza size, crust type, toppings, and dining option\*\*, while the order summary and total price are updated automatically as selections are made.



This project was developed as part of the \*\*C# learning journey\*\* to practice fundamental programming concepts and event-driven Windows Forms development.



\---



\## 🎯 Project Objectives



The main objectives of this project are to:



\* 🍕 Build an interactive pizza ordering application.

\* 🧠 Practice programming concepts using C#.

\* 🖥️ Create a desktop graphical user interface using Windows Forms.

\* 🔄 Handle user interactions through events.

\* 💰 Calculate and update the total price dynamically.

\* 🧩 Practice using different controls for different types of user input.

\* 📋 Display a live order summary based on the user's selections.

\## ✨ Features



The application includes:

\* 🍕 \*\*Choose Size\*\*

&#x20; \* Medium — $30

&#x20; \* Large — $40

\* 🥖 \*\*Choose Crust Type\*\*



&#x20; \* Thin — $0

&#x20; \* Stuffed — +$15

&#x20; \* Extra Cheese

&#x20; \* Onion

&#x20; \* Tomatoes

&#x20; \* Take Away

&#x20; \* Eat In

\## 📚 Concepts Practiced



This project focuses on practicing the following C# and Windows Forms concepts:



\* 🔹 \*\*Enums (`enum`)\*\* for representing pizza size and crust choices.

\* 🔹 \*\*RadioButton\*\* groups using `GroupBox` for single-choice options.

\* 🔹 \*\*CheckBox\*\* controls for selecting multiple toppings.

\* 🔹 \*\*Event-Driven Programming\*\* using events such as `CheckedChanged` and `Click`.

\* 🔹 \*\*Dynamic UI Updates\*\* based on user selections.

\* 🔹 \*\*Price Calculation\*\* and updating the total dynamically.

\* 🔹 \*\*Basic Form Validation\*\*.

\* 🔹 \*\*Windows Forms UI Development\*\*.
