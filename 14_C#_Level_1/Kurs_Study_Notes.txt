# C# Windows Forms Controls – Level 1

## 1. Form (`FRM`)

### 🔎 Definition

🔹 A **Form** is the main window of a Windows Forms application. It is the container where other controls are placed.

### Properties

1️⃣ **Text**
🔹 Sets the title displayed on the Form.

2️⃣ **(Name)**
🔹 Defines the name used to identify the Form in the code.

3️⃣ **Cursor**
🔹 Defines the shape of the mouse cursor when it moves over the Form.

4️⃣ **Accept Button**
🔹 Defines the default button that is activated when the user presses **Enter**.

5️⃣ **Cancel Button**
🔹 Defines the default button that is activated when the user presses **Esc**.

6️⃣ **Is MDI Container**
🔹 Determines whether the Form can contain multiple child Forms.

### Events

1️⃣ **Load**
🔹 Occurs when the Form is loaded for the first time.

2️⃣ **Paint**
🔹 Occurs when the Form is being drawn or redrawn.

---

## 2. Text Box (`TXB`)

### 🔎 Definition

🔹 A **Text Box** allows the user to enter or display text.

### Properties

1️⃣ **Enabled**
🔹 Enables or disables the Text Box.

2️⃣ **Font**
🔹 Defines the font type, style, and size.

3️⃣ **Fore Color**
🔹 Defines the color of the text.

4️⃣ **Location**
🔹 Defines the position of the Text Box on the Form.

5️⃣ **Size**
🔹 Defines the width and height of the Text Box.

6️⃣ **Tab Index**
🔹 Defines the order in which controls are selected when using the **Tab** key.

7️⃣ **Tab Stop**
🔹 Determines whether the user can reach the Text Box using the **Tab** key.

8️⃣ **Tag**
🔹 Stores additional information associated with the control.

9️⃣ **Visible**
🔹 Shows or hides the Text Box.

🔟 **Locked**
🔹 Prevents the Text Box from being moved or modified in the designer.

1️⃣1️⃣ **Dock**
🔹 Defines how the Text Box is attached to a side or area of its parent container.

1️⃣2️⃣ **Back Color**
🔹 Defines the background color.

1️⃣3️⃣ **Password Char**
🔹 Defines the character used to hide password input.

1️⃣4️⃣ **Read Only**
🔹 Allows the user to see the text but prevents editing it.

1️⃣5️⃣ **Max Length**
🔹 Defines the maximum number of characters the user can enter.

1️⃣6️⃣ **Right To Left**
🔹 Defines the text direction from right to left.

1️⃣7️⃣ **Text Align**
🔹 Defines the alignment of the text: left, center, or right.

1️⃣8️⃣ **Multi Line**
🔹 Allows the user to enter more than one line of text.

1️⃣9️⃣ **Word Wrap**
🔹 Automatically moves text to the next line when it reaches the edge.

2️⃣0️⃣ **Border Style**
🔹 Defines the appearance of the Text Box border.

2️⃣1️⃣ **Mask**
🔹 Defines a specific format for user input.

2️⃣2️⃣ **Beep on Error**
🔹 Produces a sound when invalid input is entered.

2️⃣3️⃣ **Context Menu**
🔹 Defines the context menu displayed when the user right-clicks the control.

### Events

1️⃣ **Validating**
🔹 Occurs when the control is being validated before the user leaves it.

# 📌 Important Notes

## 🟨 Common Properties

🟩 **Name**
🔹 The identifier used to reference the control in code.

🟩 **Text**
🔹 The text displayed by the control.

🟩 **Enabled**
🔹 Enables or disables the control.

🟩 **Visible**
🔹 Shows or hides the control.

🟩 **Location**
🔹 Defines the position of the control.

🟩 **Size**
🔹 Defines the width and height of the control.

🟩 **Font**
🔹 Defines the font used by the control.

🟩 **ForeColor**
🔹 Defines the text or foreground color.

🟩 **BackColor**
🔹 Defines the background color.

🟩 **TabIndex**
🔹 Defines the order of controls when using the **Tab** key.

🟩 **Anchor**
🔹 Defines how the control remains attached to the edges of its parent when the parent is resized.

🟩 **Dock**
🔹 Defines how the control is attached to an edge or fills an area of its parent container.

---

## 🟨 Common Events

🟩 **Click**
🔹 Occurs when the user clicks the control.

🟩 **DoubleClick**
🔹 Occurs when the user double-clicks the control.

🟩 **MouseEnter**
🔹 Occurs when the mouse pointer enters the control.

🟩 **MouseLeave**
🔹 Occurs when the mouse pointer leaves the control.

🟩 **KeyPress**
🔹 Occurs when the user presses a key.

🟩 **Enter**
🔹 Occurs when the control receives focus.

🟩 **Leave**
🔹 Occurs when the control loses focus.
