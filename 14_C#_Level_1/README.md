# 📘 14_C#_Level1

📣 **Learn C# and Windows Forms through concepts, practice, and desktop application development 💻⚙️**

---

## 🗝️ About This Course

**C# – Level 1** is a practical programming course focused on learning the **C# programming language** and building desktop applications using **Windows Forms**.

The course introduces the fundamentals of C#, object-oriented programming concepts, and important Windows Forms controls and components used to build interactive desktop applications.

The goal is to understand how C# works in practice and gain hands-on experience by creating Windows Forms applications.

---

## 🎯 Course Objectives

The main objectives of this course are to:

* 💻 Understand the fundamentals of the **C# programming language**.
* 🧱 Work with classes, objects, methods, properties, and events.
* 🔄 Understand basic object-oriented programming concepts in C#.
* 🖥️ Build desktop applications using **Windows Forms**.
* 🎛️ Work with common Windows Forms controls.
* 📝 Handle user input and form events.
* 📋 Work with controls such as ListView, TrackBar, NumericUpDown, TabControl, GroupBox, and Panel.
* ⚠️ Implement basic input validation using **ErrorProvider**.
* 📂 Work with file and folder selection dialogs.
* 🎨 Use ColorDialog and FontDialog to customize controls.
* 📑 Work with MenuStrip and ContextMenuStrip.
* 🪟 Understand MDI Container and parent/child forms.
* 🛠️ Practice building interactive desktop applications using C#.
